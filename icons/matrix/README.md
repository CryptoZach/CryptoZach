# Matrix strip icons (optional)

The homepage hero matrix animation loads PNGs from this folder when present. If a file is missing or fails to load, that icon is skipped and text-only glyphs still render.

**Generate assets (recommended):** from repo root run **`npm run build:matrix-icons`**. That script pulls Simple Icons (jsDelivr + Iconify), Iconify `token/*` / `cryptocurrency-color/*` where needed, and spothq cryptocurrency-icons PNGs, then writes **32×32 white-on-transparent** PNGs via Playwright. The manifest matches **`script.js`** `iconDefs` (no orphan filenames). After replacing PNGs, bump **`mtxIconAssetVer`** in **`script.js`** (matrix icon loader) so browsers do not mix cached old and new silhouettes.

**Sourcing help:** paste-ready prompt for an LLM (manifest, license constraints, filenames) lives in **[`docs/OPUS_MATRIX_ICONS_PROMPT.md`](../docs/OPUS_MATRIX_ICONS_PROMPT.md)**. **`venmo.png`** uses Iconify **`fa7-brands/venmo-v`** (Font Awesome Brands, **CC BY 4.0**); attribute Font Awesome if you redistribute the SVG source. **`wise.png`** uses bundled **`wise.svg`** (path from **Lineicons**, **MIT**; attribute Lineicons if you redistribute the SVG source). **`mstr.png`** uses bundled **`strategy-logo-2025.png`** (from **`Strategy_logo_(2025).svg.png`**: Strategy wordmark + **₿**; Simple Icons still ships the legacy MicroStrategy bars as fallback).

**Expected files (24px or 32px PNG, transparent background):** **105** on-disk PNGs (**54** crypto tickers + **51** company); **`script.js`** `iconDefs` references a subset (for example **Facebook**, **Fidelity**, **Stripe**, **`link.png`**, **`hnt.png`**, and **`atom.png`** are not in the hero pool). **`script.js`** `iconDefs` may list the same `*.png` more than once (for example **`eth.png`**, **`usdc.png`** listed three times, **`uni.png`**, **`aave.png`**, **`crv.png`**, **`arb.png`**, **`ton.png`** twice in crypto, **`op.png`** once, and **`jpm.png`** twice in companies) to weight those streams. Authoritative manifest for sourcing is **`docs/OPUS_MATRIX_ICONS_PROMPT.md`**. Some marks have **no Simple Icons slug**, or the CDN art **whiten()**s to a blob (filled disk + foreground): place **`build-sources/<name>.svg`**, or rely on Iconify in **`npm run build:matrix-icons`** (for example **`metamask`**, **`uni`** via **`token/uniswap`**), or see bundled **`usdc.svg`**, **`dai.svg`**, **`hbar.svg`**, **`cashapp.svg`**, **`avax.svg`**, **`wormhole.svg`**, **`zrx.svg`**, **`kraken.svg`**, **`coinbase.svg`**, **`hyperliquid.svg`** (**`hyper-foundation.svg`**; **`hyperliquid.png`** from **`npm run build:matrix-icons`**; archived blob **`hyperliquid-hl-symbol.svg`**), **`arb.svg`**, **`ltc.svg`**, **`wfc.svg`**, **`gs.svg`**, **`amd.svg`**, **`op.svg`**, **`near.svg`**, **`sui.svg`**, **`sei.svg`**, **`dot.svg`**, **`doge.svg`**, **`aave.svg`**, **`crv.svg`**, **`layerzero.svg`**, **`cantor.svg`**, **`clearstreet.svg`**, **`wise.svg`**, **`kinexys.svg`**, **`nasdaq.svg`**, **`nyse.svg`**, **`ice.svg`**, **`citi.svg`**, **`jpm.svg`**; **`link.png`** from bundled **`link.svg`**; **`apt.png`** / **`wld.png`** from Iconify (**`token/aptos`**, **`arcticons/worldcoin`**).
