Patents

Patent-pending systems.

37 filed USPTO applications across 27 families. Most describe infrastructure for running many AI agents on one shared codebase at the same time: keeping their edits from overwriting each other, requiring every output to point at the evidence behind it, keeping a tamper-evident record of what changed and who changed it, and governing when an agent may start, stop, or hand unfinished work to another. The rest cover measurement itself, and the attribution of control in pseudonymous on-chain systems. One describes the combination: how those mechanisms compose into one architecture.

All 37, grouped by primary function; several span more than one area. Each group opens with the problem in plain terms, then lists the filings that address it.

Concurrent repository integrity Two agents writing to the same repository at the same time can overwrite or lose each other's work, and the failure usually shows up only under one specific ordering of events, which makes it hard to reproduce and easy to miss.

  • Multi-session staging isolation and multi-mode verification64/071,767
  • Push-time and landing concurrency control64/095,598
  • Unsupervised autonomous-agent write integrity64/095,603
  • Conflict-halting concurrent publication64/096,039
  • Authorship-based commit-replay narrowing with edit-intent ledger collision gating64/107,827
  • Pre-commit write-collision detection and classification64/109,514
  • Distinguishing false write contention from true write contention, recorded as a counted verdict class64/137,910

Evidence and retrieval quality A language model states things with the same confidence whether or not a source supports them, and will retrieve a plausible wrong document as readily as the right one.

  • Evidence-grounding for cited values64/102,816

Coordination, fleet governance, and session continuity An agent can exit in the middle of a task, and work marked as owned by a process that no longer exists is invisible to every other agent, so it sits untouched indefinitely.

Measurement and detector validity A detector nobody has shown can fire on a real fault, and stay quiet on a clean one, is an assumption wearing an instrument's clothes. These separate a measurement that came back negative from one that never ran.
